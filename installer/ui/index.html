    Bienvenue dans NEXUL

    Cet assistant installe le langage NEXUL sur votre ordinateur : le compilateur natif, ses outils et NEXUL Studio, l'environnement de développement officiel.

    Compilateur natif

    nxc compile en code machine optimisé (LLVM) pour Windows, Linux, macOS, WebAssembly et les microcontrôleurs.

    NEXUL Studio

    Éditeur avec complétion, documentation au survol, refactorisation, tests et aperçu web.

    Débogueur

    Points d'arrêt, pas à pas, variables et pile d'appels directement dans Studio.

    Paquets nxpm

    Dépendances locales ou Git, versions figées et vérification d'intégrité SHA-256.

    Anciennes versions

    Des versions précédentes de NEXUL ont été trouvées sur cet ordinateur. Choisissez pour chacune de la supprimer ou de la sauvegarder.

    Une sauvegarde est déplacée dans . Elle est retirée du PATH et n'a plus de raccourci, d'association de fichiers ni d'inscription dans les applications installées : elle ne gêne pas la nouvelle version. Pour vous en débarrasser plus tard, supprimez simplement son dossier.

    Composants

    Choisissez ce qui doit être installé. Les éléments indispensables au compilateur sont toujours installés.

    Emplacement et options

    NEXUL s'installe pour votre compte utilisateur, sans droits d'administrateur.

    Les programmes sont placés dans bin ; LLVM dans llvm ; les exemples dans examples.

    Installation en cours

    Les fichiers sont décompressés et vérifiés un par un.

    Désinstaller NEXUL

    Le compilateur, NEXUL Studio, la chaîne LLVM, les raccourcis, l'association des fichiers .nx et l'entrée du PATH seront supprimés.
    Vos projets et vos réglages ne sont pas touchés.
